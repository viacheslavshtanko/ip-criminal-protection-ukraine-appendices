# Масиви судових рішень (ЄДРСР)

Джерело — Єдиний державний реєстр судових рішень (reyestr.court.gov.ua) і його відкриті дані. Поле `url` у кожному файлі веде до тексту документа в реєстрі; тексти рішень тут не відтворюються. Реєстр подає рішення знеособлено. Ні в кодуванні, ні в цих файлах немає імен учасників справ, їхніх адрес чи уривків текстів рішень. Як збирали і кодували масиви, описано в [`../methodology/data_collection.md`](../methodology/data_collection.md).

Кодування CSV — UTF-8, роздільник — кома. `н/д` означає, що в тексті рішення цих відомостей немає.

## 1. `criminal_verdicts_944.csv` — кримінальні справи (944)

Одиниця — справа: останній вирок першої інстанції у справі, ухвалений після повторних розглядів (книга, 3.3.3). Масив охоплює злочини, передбачені ст. 176, 177, 203-1, 229, 231 і 232 КК України.

| Період | Справ |
|---|---|
| до 2012 р. | 513 |
| 2013–2021 рр. | 339 |
| 2022–2026 рр. | 92 |
| **Разом** | **944** |

Вироки за видом: обвинувальних — 900, виправдувальних — 30, змішаних — 10, вид не визначено — 4. Число 944 — верхня межа кількості проваджень (див. методику).

| harm_by | правовласник-представник / державний експерт (НДЕКЦ, КНДІСЕ тощо) / приватний експерт (судовий експерт ІВ) / слідчий-прокурор / суд / н/д | хто розрахував |

| punishment | штраф (сума) / обмеження волі / позбавлення волі з випробуванням / позбавлення волі реально / звільнення / н/д | основне покарання |
| confisc | знищення-конфіскація предметів / повернення / н/д | доля контрафакту, обладнання |
| war | так / ні | згадка воєнного стану як обставини |

**Правила кодування:**
1. Якщо обвинувачених кілька, кодуються статус і роль основного з них — першого в резолютивній частині.
2. «ФОП» має пріоритет над «продавцем», якщо особа торгувала від власного імені.
3. Суми наведено в гривнях, як у вироку, без перерахунку.
4. Якщо відомості сумнівні, ставиться `н/д`.

### Нормалізовані поля (суфікс `_n`)

Поля з суфіксом `_n` — ті самі ознаки, зведені до укрупнених категорій, за якими рахувалися таблиці розд. 5–6 книги. Перелік: verdict_n, deal_n, acc_status_n, prior_conv_n, channel_n, origin_n, goods_n, victim_n, rep_n, detect_n, harm_base_n, civil_claim_n, punishment_n, war_n.

## 2. `civil_commercial_15973.csv` — цивільні й господарські суди (15 973 документи)

Масив до розд. 7 книги: рішення й постанови цивільних і господарських судів у спорах щодо ІВ та недобросовісної конкуренції (злитий масив від 12.11.2026). Документи всіх інстанцій відповідають 6 165 справам першої інстанції. З них 12 750 документів стосуються ІВ (`ip` = 1). Суми витягнуто автоматично з резолютивної частини, тому вони мають похибку; книга використовує їх із поправками, описаними в 7.2.
